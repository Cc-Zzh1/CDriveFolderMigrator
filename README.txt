C 盘文件夹迁移工具

为 C 盘减负，把游戏存档、浏览器用户数据和大型软件配置迁移到其他盘，同时保留原来的访问路径。

适用系统：
- 推荐 Windows 10 / Windows 11。
- 可用于带桌面体验的 Windows Server 2016/2019/2022。
- 需要 Windows PowerShell 5.1、.NET Framework WinForms、robocopy、mklink。
- 不支持 macOS / Linux；不建议用于 Windows 7/8/8.1 等旧系统。
- 迁移当前用户目录下的数据通常不需要管理员权限；不要迁移系统目录或驱动仓库。

用法：
1. 双击“启动_C盘文件夹迁移工具.cmd”。
2. 选择要迁移的 C 盘源目录。
3. 选择目标根目录，例如 E:\AppDataMigrated。
4. 点击“预估大小”，确认目录大小。
5. 确认相关程序已经关闭后，点“迁移所选”。

工作方式：
- 先用 robocopy 复制源目录到目标盘。
- 校验源目录和目标目录大小。
- 把原目录移动为临时备份。
- 在原路径创建目录联接。
- 程序仍访问原 C 盘路径，真实数据在目标盘。
- 在目标根目录写入“迁移来源清单.csv”和“迁移说明.txt”。
- 如果界面切换为 English，新生成的记录文件会使用 migration-sources.csv、migration-notes.txt、migration-log.txt。

实际案例：
- Chrome User Data 这类浏览器用户数据可能占用数 GB 空间。
- 迁移后 C 盘路径仍然会存在，这是目录联接入口；真实数据在目标盘。
- README.md 里有 C 盘入口和 E 盘真实目录的截图对照。

还原说明：
- “还原迁移”只读取当前“目标根目录”下的记录文件，不会扫描整个 E 盘。
- 中文界面优先读取“迁移来源清单.csv”。
- 英文界面优先读取“migration-sources.csv”。
- 如果当前语言的记录文件不存在，会再尝试另一种命名。
- 如果提示找不到清单，通常是目标根目录填错了，应填写迁移时用的根目录，例如 E:\AppDataMigrated。
- 记录 CSV 必须直接放在目标根目录下；如果手动移动目标根目录，要把 CSV 一起移动过去。
- 如果只手动移动了某个已迁移子目录，需要同步修改 CSV 里的 MigratedPath，否则工具可能找不到真实目录。
- 还原成功后，如果原路径旁边存在工具生成的 *_backup_migrated_yyyyMMdd_HHmmss 临时备份，工具会同步删除；删除失败时会在日志提示手动检查。

注意：
- 不确定目录用途时，迁移前建议先把完整路径发给 AI 询问，或搜索确认是什么软件在使用。
- 不要迁移 C:\Windows、C:\Program Files、DriverStore、整个 AppData。
- 适合迁移游戏存档、浏览器用户数据、大型软件配置目录。
- 迁移 Chrome、游戏启动器等目录前，请先完全退出相关程序。
- 如果勾选“迁移成功后删除临时备份”，确认迁移无误后 C 盘不会保留原始副本。
